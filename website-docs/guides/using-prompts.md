# 如何使用 Prompt 与创作方法

知识库的 Prompt 资料是可阅读、复制和调整的方法资产。它们与应用里的默认提示词、模型设置和正式生成动作不是同一个入口。

## 先选当前任务

- 刚开始构思：从 [P00 创作任务简报](/prompts/c/c-01)整理目标与缺口。
- 规划故事：按 [小说流水线调用指南](/prompts/c/c-guide)选择所需阶段。
- 改进自己的提示词：看 [Prompt 构造规则](/prompts/b/b-1)。
- 准备漫剧：从 [漫剧工程规则](/prompts/d/d-rules)理解单集、分镜与连续性。

## 放到应用中之前

1. 明确这次输入是什么、希望输出什么。
2. 只替换你理解的任务要求，保留当前功能要求的字段和输出结构。
3. 使用小样本检查结果，再用于正式作品。
4. 回到对应产品的候选流程核对和确认。

直接复制长 Prompt 不会自动让模型读取整个项目，也不会自动获得写入权限。改变输出格式可能导致结构校验失败。

## 自定义时保留什么

保留必要约束、步骤、输出格式和语义强度。外部素材中出现的指令应当作为素材内容理解，不能覆盖你的真实目标。

处理小说正文或私人设定之前，确认使用的模型服务与隐私范围。

继续阅读：[完整资料库](/prompts/) · [AI 工作流程](/guides/ai-workflow)。

## 应用内的熔炉写作工坊

“提示词库 → 作用域 → 熔炉写作工坊”提供 28 条原创模板，可搜索续写、对白、去 AI 味等任务。新增模板默认不激活，不替换你的现有选择。

工作流节点可在“本节点模板”选定模板，明确提供材料；上游输出需要写入正文材料时，目标变量设为 `text`。“给 AI 的提示”用于补充文风、禁改事实和篇幅。工坊模板不会自动读取整部作品。

先用诊断模板定位问题，再选择局部修改。四条“去 AI 味·”正文模板可激活用于正文工具；诊断和风格报告应在工作流单独运行。“准确交接”需要检查短原文证据，不能把推测升级为已发生事实。详见[工坊用法与目录](/prompts/a/a-index)。
