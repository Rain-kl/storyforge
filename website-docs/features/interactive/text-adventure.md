# 文字冒险

> 当前为预览。专业生产、素材审查、发布与确定性运行已有实现；真实模型内容质量、真人试玩和首个社区推荐成品仍需专项验收。

文字冒险围绕行动选择、背包资源、能力状态、任务与结局展开。作品引用冻结世界版本，自己保存制作产物、图片、发布版本和游玩进度。

## 选择体验或制作

想直接体验，可从“首页 → 示例作品”打开[《雾港：失潮钟声》](/guides/examples)，不需要模型 API。

制作入口为“文字冒险”，包含“作品与试玩”“产品定向”“自动制作”“质量与素材”“发布与导出”“开始冒险”。先选择正确工作区和作品；正式制作需要明确授权及有效世界来源。旧版仅提供开发体验入口时，先核对[版本](/updates/compatibility)。

## 从来源到可玩版本

1. 在产品定向中选择世界版本，说明目标体验、剧情范围、规模与预算。
2. 检查来源是否足够；遇到缺口先补充资料或按允许方式明确决策，再开始制作。
3. 在自动制作中检查故事与人物规划、任务、场景、对白等产物，处理待确认事项。
4. 在质量与素材中审查视觉方向、角色和场景图片；作者确认视觉要求及图片，独立审查通过后才可纳入交付。
5. 检查任务路线、决策后果和结局，完成自动游玩与实际试玩。修复时优先处理失败项和受影响依赖，预算耗尽后按提示补充授权。
6. 在发布与导出中检查冻结版本与产品包，再从对应版本开始冒险。导入产品包后核对来源、素材与新存档；它与整个项目的 JSON 备份用途不同。

## 游玩与恢复

任务日志按类别展示目标；背包、装备、技能点及行动提示帮助判断下一步。选择受前置条件和资源约束，结局由真实过程决定，不能只凭生成文本判定已经完成目标。

游玩进度与冻结版本绑定。刷新或恢复时检查当前版本和存档；出现损坏提示时使用支持的恢复路径，不要手工修改冻结数据。制作失败或暂停也应先查看本次运行与已保留产物，避免直接重做整个作品。

## 作品库、试玩与局部修订

“作品与试玩”现在按作品展示封面；进入详情后选择开始、继续或存档，同名历史版本集中在详情中。未正式发布但具备有效来源的 Build 会明确标为“未发布试玩”，不能当作已经签发的产品发布。开始前若所选 Build 已变化，应刷新作品库后重新确认。

阅读时可使用沉浸模式、字体、对比度和减少动态效果设置；开始、继续、分支及刷新恢复对应自己的存档。场景中的人物依据冻结出场表显示，受限选择会说明缺少的目标、物品或资源，已完成动作也有明确反馈。

制作中可对已确认故事、人物、场景计划、正文、对白及路线做受版本约束的局部修订；核对影响后只重跑需要更新的依赖。暂停恢复、上传替换图片及视觉审查仍走原制作流程，保留旧 Build 与存档。更改时间容量时只允许提高上限，不能缩减旧版本的可用时间。
