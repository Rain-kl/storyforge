# 末班来信 · 动态漫画展示

50 秒原创有限动画样片。入口为「漫画 → 作品库」及「首页 → 示例作品 → 漫画」；在独立标签页播放，支持暂停、重播、进度拖动、音量、全屏和静帧对照。

## 产品与作品边界

这是漫画产品的预制展示作品，属于产品展示研发，不经过世界 S1/S2/S3，也不声称由当前漫画生产流程自动生成。它不创建 Work、候选、Release 或存档，不调用模型，不访问作者数据库；CONTEXT_SOURCES、FIELD_REGISTRY / Adoption、PROJECT_TABLES、schema 和源作品保持不变。

媒资由此展示作品持有，交接物为静态播放器、八张画面／图层及音轨。它演示分层运动、眨眼、镜头、雨雾与配乐，不包含自然行走、口型同步或复杂肢体表演。

## 文件与来源

- 播放器与媒资：`public/demo-assets/last-letter/`。
- 八张原图由内置 image_gen 制作，完整提示词见 `prompts.json`；PNG 转为无损 WebP，已逐像素比较 RGBA/RGB 解码结果，保持尺寸、颜色与透明度。
- 音轨由固定随机种子的程序合成，包含原创钢琴式旋律、铺底、雨声、钟表和汽笛，没有配音或商业歌曲。
- `assets.json` 记录分辨率、文件字节数、SHA-256 和音轨时长。

画面按进入播放器加载，声音由用户明确点击播放后开始。离开标签页时暂停，返回后由用户继续。影片资源不进入应用的 PWA 预缓存，静态 HTML 路径不走 SPA 导航回退；观看本身不承诺断网可用。静帧对照保留切镜、字幕和声音，只关闭当前画面的实时动效。

原始试片的自包含 HTML 和 MP4 是同一素材的重复交付格式，不放入应用首屏或 Git；线上展示保留实时 HTML 播放形式。播放器不需要额外依赖。

## 验证与回退

`tests/e2e/comic-motion-showcase.spec.ts` 检查两个入口、无作者数据写入、按需加载、播放／暂停／拖动／重播、静帧对照、刷新、图片失败和无声音降级。生产预览同时验证 `/storyforge/` 子路径及 PWA 路由与预缓存隔离。

回退此增量时一起移除展示卡片、静态目录及相应文档入口；不需要数据迁移。
